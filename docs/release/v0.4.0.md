# web-net v0.4.0 - Actions

**Forms, uploads, and CSRF on every state-changing request.**

## Highlights

- **CSRF by default.** Every `POST`, `PUT`, `PATCH`, and `DELETE` passes csrf-sec's origin policy and a session-bound token before any hook or handler runs. An application with such a route and no `Builder::csrf(..)` does not build; a route opts out only with `csrf_exempt(reason)`.
- **The token is always checked before the data is used.** From `X-CSRF-Token`, or the `csrf_token` field: a urlencoded form's token is checked before the handler; a multipart form's in the same pass that reads it, before any file byte is stored. The raw body stays locked until then, and a handler that never reads its multipart form has its reply replaced with 403.
- **Forms and uploads** through form-net: `Cx::form::<T>()` with per-route limits, `form_inspected` with a content inspector, and `Cx::upload` (feature `uploads`). The error keeps form-net's detail so an action can render the form again with 422; `?` maps it to its status.
- **External redirects** only to hosts listed with `redirect_hosts`.
- **Preconditions**: `Cx::precondition` answers 412 for a false `If-Match` or `If-Unmodified-Since`.

## Compatibility

Applications with unsafe-method routes need `Builder::csrf(..)` or `csrf_exempt(reason)` on those routes; `build()` names each one. New dependencies: form-net 0.9 and csrf-sec 0.9.3 (both re-exported).

# web-net v0.11.0

Moves to serve-net 0.9, which adds HTTP/2.

- web-net's own API is unchanged. Code that names serve-net types beside web-net (`HttpRequest`, `Envelope`, `HttpReply`) moves to `serve-net = "0.9"` too; that is the whole migration.
- Static files over HTTP/2: serve-net cannot send a reply in parts on an HTTP/2 stream yet, so files up to 16 MiB go whole there and larger ones are refused with 500. HTTP/1.1 still sends large files in parts.
- A later part of a large file whose record is gone now ends the connection instead of starting the file again.

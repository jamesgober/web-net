# web-net v0.10.1

Moves to serve-net 0.8.1. serve-net 0.4.0 to 0.7.1 are yanked for two security fixes, so web-net 0.10.0 can no longer be resolved from scratch; this release can.

- serve-net now answers a TLS request whose `Host` names another server than the TLS server name with 421, before web-net sees it.
- `Request::tls()` gives a gate the TLS handshake: the server name, the protocol, and the SHA-256 of a verified client certificate's public key.
- web-net's own API is unchanged. Code that names serve-net types beside web-net (`HttpRequest`, `Envelope`, `HttpReply`) moves to `serve-net = "0.8"` too.

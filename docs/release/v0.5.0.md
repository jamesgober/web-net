# web-net v0.5.0 - Negotiation and caching

**APIs, browsers on other origins, caches in front, and several sites on one server.**

## Highlights

- **JSON error replies** for clients that prefer `application/json`, with the same facts as the page and still no detail. `Cx::language` and `Cx::media` pick from a request's preferences.
- **CORS** declared per route or group (`Cors`): preflights answered before the gate, reply fields only for allowed origins, `Vary: origin`, and `*` never with credentials. Routes without a policy never answer with CORS fields.
- **Compression** (`Builder::compress`): gzip through compress-lib for text, JSON, XML, and SVG over 1 KiB, kept only when smaller. Off by default.
- **Cache policies** (`CachePolicy`) per route or group, including `Guests`: public for guests, private for signed-in visitors. `App::serve` returns `Served` with a cacheability report a cache in front can trust: a reply is keepable only for a guest's `GET`/`HEAD`, status 200, no cookie, no `Vary` but `Accept-Encoding`.
- **Several sites** (`Sites`): the listed host wins, then the longest base path.
- **`Hook::BeforeRender`**.

## Compatibility

No signature changed. New dependency: compress-lib 0.9.

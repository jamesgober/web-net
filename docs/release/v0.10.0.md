# web-net v0.10.0 - Simplified

**The common case in a line or two, and an independent review's fixes.** A site, a route, and a handler each read as one obvious line, with one way to do each thing and names that say what they touch.

```rust
use web_net::{App, get};

App::builder()
    .route(get("/", |cx| cx.html(200, "<h1>Hello</h1>")))
    .route(get("/posts/:slug", |cx| cx.text(200, &cx.param("slug")?)))
    .build()?
    .listen("127.0.0.1:8080")?
    .wait();
```

## Highlights

- **`App::listen(addr)`**: serve a site without serve-net's builder or a second dependency.
- **Handlers end with their reply**: `cx.html`, `cx.text`, and the new `cx.bytes` return `Result`, so no `; Ok(())`. The handler type is `Context`.
- **No `.public()` on a site without sign-in**: with the `Open` gate every route is public. With a gate that has rules, a route that declares no access still stops the build, and a group's rule holds for every route in it.
- **Safe defaults from the review**: a site with no declared host answers only `localhost` (DNS rebinding), hidden routes stay hidden from 405 and `OPTIONS`, `cx.url` builds only links inside the site, and every panic in the application's code is caught and answered.
- **Large downloads are never corrupted**: a reply in parts keeps its record to its end; under pressure a new one is refused with 503, never an old one forgotten.
- **Faster static files**: cached resolutions and small files' bytes.
- **A reference that compiles**: `docs/API.md` covers every public item and runs as doctests, with the README; every public item has its own example.

## Migration from 0.9

This release breaks the 0.9 API on purpose. Every change:

| 0.9 | 0.10 |
|---|---|
| `serve_net::Server::builder().listener(ListenerSpec::tcp("web", addr)).serve(app)?` | `app.listen(addr)?` (the builder still works for TLS and other limits) |
| A site with no `.host(..)` answered every `Host` | it answers the development hosts only; add `.host("example.com")` before deploying, or `.any_host()` |
| `Cx` | `Context` |
| `cx.html(200, s); Ok(())` | `cx.html(200, s)` (also `text`); in the middle of a handler, `cx.html(200, s)?;` |
| `cx.set_header("content-type", t); cx.body_bytes(b); Ok(())` | `cx.bytes(200, t, b)` |
| `get(..).public()` with `App::builder()` (the `Open` gate) | `get(..)`; `.public()` still compiles and still declares |
| `cx.param("x").unwrap_or_default()` | `cx.param("x")?` |
| `cx.url(path)` | `cx.url(path)?` (refuses a target that is not a site path); `cx.url_path(&[..])` for segments from input |
| `cx.see_other(path)` | `cx.redirect(303, path)` |
| `cx.media(offers)`, `cx.language(offers)` | `cx.accept(offers)`, `cx.accept_language(offers)` |
| `cx.body_mut()` | `cx.reply_buffer()` |
| `App::with(gate, engine)` | `App::with_gate(gate).render(engine)` |
| `app.respond(req, env, reply)` | `app.respond(req, env, None, reply).outcome`, or the `HttpService::call` it already had |
| `app.respond_identified(req, env, who, reply)` | `app.respond(req, env, Some(who), reply).outcome` |
| `app.serve(req, env, who, reply)`, `sites.serve(..)` | `app.respond(req, env, who, reply)`, `sites.respond(..)` |
| A wrapper that calls the app | also forwards serve-net's `done`: `HttpService::done(&app, env, finished)` |
| A route's `.allow(r)` inside a group with `.allow(g)` replaced `g` | both hold; a `.public()` route inside a group with a rule stops the build (move it out of the group) |
| `Denial::status(429, code)`, `denial.status_code()` | `Denial::with_status(429, code)`, `denial.status()` |
| `Builder::challenge(v)` | `Builder::www_authenticate(v)` |
| `Group::new(prefix)` | `Group::at(prefix)` |
| `web_net::csrf_sec::OsPads` (csrf-sec 0.9) | `web_net::csrf_sec::OsRandom` (csrf-sec 0.10); `cookie_net` is 0.8, `form_net` 0.10 |
| A reference shown as `1a-2` | 16 hexadecimal digits; `RequestId::connection()` and `seq()` keep the raw values |

`Render`, `Output`, the view types, `Gate`, and `Identity` are unchanged, and `ErrorPage` only gained `base` and `url`, so template engines and gates need only the version bump.

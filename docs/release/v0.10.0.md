# web-net v0.10.0 - Simplified

**The common case in a line or two.** A site, a route, and a handler each read as one obvious line, with one way to do each thing and names that say what they touch.

```rust
use web_net::{App, get};

App::builder()
    .route(get("/", |cx| cx.html(200, "<h1>Hello</h1>")))
    .route(get("/posts/:slug", |cx| cx.text(200, &cx.param("slug")?)))
    .build()?
    .listen("127.0.0.1:8080")?
    .wait();
```

## Highlights

- **`App::listen(addr)`**: serve a site without serve-net's builder or a second dependency.
- **Handlers end with their reply**: `cx.html`, `cx.text`, and the new `cx.bytes` return `Result`, so no `; Ok(())`.
- **No `.public()` on a site without sign-in**: with the `Open` gate every route is public. With a gate that has rules, a route that declares no access still stops the build.
- **One way per job, plain names**: one `App::respond` for fronts, `redirect(303, ..)` instead of `see_other`, `accept` and `accept_language`, `reply_buffer`, `www_authenticate`, `Denial::with_status`, `Group::at`.
- **A gate outage is retryable**: `Denial::unavailable(code)` answers 503 (with `Retry-After` through `.retry_after(seconds)`) when a gate's stores are down, instead of a 403.
- **Error pages inside the folder**: `ErrorPage::base` and `ErrorPage::url(path)`, so an engine's error page for a site under `/blog` links `/blog/static/site.css`.
- **A reference that compiles**: `docs/API.md` covers every public item and runs as doctests, with the README.

## Fixed

- A path that decodes to a C1 control character (U+0080 to U+009F, such as `%C2%85`, NEL) is refused with 400, as other control characters always were.

## Migration from 0.9

This release breaks the 0.9 API on purpose. Every change:

| 0.9 | 0.10 |
|---|---|
| `serve_net::Server::builder().listener(ListenerSpec::tcp("web", addr)).serve(app)?` | `app.listen(addr)?` (the builder still works for TLS and other limits) |
| `cx.html(200, s); Ok(())` | `cx.html(200, s)` (also `text`); in the middle of a handler, `cx.html(200, s)?;` |
| `cx.set_header("content-type", t); cx.body_bytes(b); Ok(())` | `cx.bytes(200, t, b)` |
| `get(..).public()` with `App::builder()` (the `Open` gate) | `get(..)`; `.public()` still compiles and still declares |
| `cx.param("x").unwrap_or_default()` | `cx.param("x")?` |
| `cx.see_other(path)` | `cx.redirect(303, path)` |
| `cx.media(offers)`, `cx.language(offers)` | `cx.accept(offers)`, `cx.accept_language(offers)` |
| `cx.body_mut()` | `cx.reply_buffer()` |
| `App::with(gate, engine)` | `App::with_gate(gate).render(engine)` |
| `app.respond(req, env, reply)` | `app.respond(req, env, None, reply).outcome`, or the `HttpService::call` it already had |
| `app.respond_identified(req, env, who, reply)` | `app.respond(req, env, Some(who), reply).outcome` |
| `app.serve(req, env, who, reply)`, `sites.serve(..)` | `app.respond(req, env, who, reply)`, `sites.respond(..)` |
| `Denial::status(429, code)`, `denial.status_code()` | `Denial::with_status(429, code)`, `denial.status()` |
| `Builder::challenge(v)` | `Builder::www_authenticate(v)` |
| `Group::new(prefix)` | `Group::at(prefix)` |

`Render`, `Output`, the view types, `Gate`, and `Identity` are unchanged, and `ErrorPage` only gained `base` and `url`, so template engines and gates need only the version bump.

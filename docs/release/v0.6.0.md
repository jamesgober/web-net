# web-net v0.6.0 - Performance

**Nothing allocated on the warm path, and a measured cost per request.**

## Highlights

- **No allocation per request** on the warm path, counted by a global allocator against bare serve-net (`tests/alloc.rs`): 0.00 on both. Host checks no longer copy the host, `Cache-Control` values are made at build, and `Accept` is parsed only when it names JSON.
- **Benchmarks** (`benches/web.rs`, criterion) of web-net against bare serve-net: about 0.7 µs of web-net's own work per request, plus about 0.35 µs for the default security headers (mostly serve-net writing the extra fields), on a loaded machine. Lookup at 10,000 routes costs the same as at 10. Method and numbers: `docs/PERFORMANCE.md`.
- **10,000 routes** build and resolve correctly (`tests/scale.rs`).

## Compatibility

No API or behaviour change. criterion is a dev-dependency only.
